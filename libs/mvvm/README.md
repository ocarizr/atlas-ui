# MVVM runtime

`atlas::mvvm` provides immutable data-defined schemas, typed observable state,
named actions/events, bounded owner dispatch and instance-bound subscriptions.
It depends on diagnostics; it does not depend on UI, XML, input or a scheduler.

See [ViewModel contracts](../../docs/mvvm.md). Authoring is in
[`mvvm_content`](../mvvm_content/README.md); UI integration is in
[`ui_mvvm`](../ui_mvvm/README.md).
